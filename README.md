# GITOcorp Studios · Web v2

Web estática preparada para GitHub Pages.

## Contenido

- `index.html`: landing general de GITOcorp Studios.
- `apps/infiltrado/index.html`: página de Infiltrado.
- `apps/realfood-planner/index.html`: página de RealFood Planner.
- `apps/noche-de-juegos/index.html`: página de Noche de Juegos.
- `apps/danoquiz/index.html`: página de DanoQuiz.
- `privacy/infiltrado.html`: política de privacidad de Infiltrado.
- `privacy/realfood-planner.html`: política de privacidad de RealFood Planner.
- `privacy/noche-de-juegos.html`: política de privacidad de Noche de Juegos.
- `privacy/danoquiz.html`: política de privacidad de DanoQuiz.
- `assets/styles.css`: estilos globales.
- `assets/favicon.svg`: icono simple de GITOcorp.

## URLs recomendadas para App Store Connect

Si usas un dominio propio:

- Infiltrado: `https://TU-DOMINIO/privacy/infiltrado.html`
- RealFood Planner: `https://TU-DOMINIO/privacy/realfood-planner.html`
- Noche de Juegos: `https://TU-DOMINIO/privacy/noche-de-juegos.html`
- DanoQuiz: `https://TU-DOMINIO/privacy/danoquiz.html`

Si usas GitHub Pages sin dominio propio, cambia `TU-USUARIO` y `TU-REPO`:

- `https://TU-USUARIO.github.io/TU-REPO/privacy/infiltrado.html`
- `https://TU-USUARIO.github.io/TU-REPO/privacy/realfood-planner.html`
- `https://TU-USUARIO.github.io/TU-REPO/privacy/noche-de-juegos.html`
- `https://TU-USUARIO.github.io/TU-REPO/privacy/danoquiz.html`

## Notas

Los enlaces internos son relativos, así que la web funciona tanto con dominio propio como en GitHub Pages dentro de un repositorio.

Los textos de privacidad son una base conservadora para versiones iniciales/locales. Antes de publicar cada app, conviene ajustar cada política a las funciones reales que tenga esa build: iCloud, Game Center, fotos, notificaciones, backend, analítica o APIs externas.
