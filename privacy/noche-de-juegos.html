1. Resumen

Noche de Juegos está pensada para guardar la información de la ludoteca y los retos en el dispositivo, salvo que el usuario active funciones externas en versiones futuras.

Idea principal: GITOcorp Studios no vende datos personales, no crea perfiles publicitarios y no comparte información con anunciantes.

2. Datos que puede guardar la app

Dependiendo de la versión instalada y del uso que haga el usuario, la app puede guardar información necesaria para que sus funciones principales trabajen correctamente:

  • Juegos añadidos, retos, notas, fotos seleccionadas por el usuario y registros de partidas.
  • Preferencias de notificaciones, como recordatorios para jugar, si el usuario las activa.
  • Fechas de retos o partidas para poder consultar el histórico.

Las fotos solo se usarán cuando el usuario conceda permiso y seleccione imágenes. Si en futuras versiones se integra una fuente externa de datos de juegos, la política se revisará para explicarlo claramente.

3. Cómo se usa la información

La información introducida en la app se utiliza para prestar las funciones que el usuario solicita: mostrar pantallas, guardar progreso, recuperar configuraciones, ordenar contenidos y mejorar la experiencia dentro de la propia aplicación.

No utilizamos esta información para publicidad personalizada ni para venderla a terceros.

4. Permisos del dispositivo

La app solo solicitará permisos del dispositivo cuando una función concreta lo necesite. Por ejemplo, acceso a fotos para seleccionar una imagen, notificaciones para enviar recordatorios o funciones de red si una versión futura incorpora sincronización o servicios externos.

El usuario puede aceptar, rechazar o modificar estos permisos desde los ajustes de iOS.

5. Servicios de terceros

La versión inicial de la app está planteada sin cuentas propias de GITOcorp Studios. Algunas funciones pueden apoyarse en servicios de Apple, como TestFlight, App Store, iCloud, Game Center o notificaciones del sistema, cuando estén disponibles o sean activadas por el usuario.

Esos servicios se rigen también por las políticas y controles de privacidad de Apple. Si se incorporan otros proveedores o servicios externos, esta página se actualizará para indicarlo de forma clara.

6. Menores

La app no está diseñada para recopilar datos personales de menores de forma deliberada. Si un padre, madre o tutor considera que se ha introducido información que deba eliminarse, puede contactar con nosotros.

7. Cambios en esta política

Podemos actualizar esta política cuando la app cambie, incorpore nuevas funciones o necesite reflejar mejor cómo trata la información. La fecha de actualización aparecerá siempre al inicio de la página.

8. Contacto

Para consultas de privacidad, soporte o solicitudes relacionadas con esta app, puedes escribir a gito@gitocorp.com.
